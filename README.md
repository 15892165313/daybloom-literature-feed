# DayBloom Literature Feed

本仓库只发布适合 DayBloom 读取的**可公开论文元数据与周报分析**。请勿提交个人日程、私人笔记、未公开研究数据或访问令牌。

- `data/papers/latest.json`：最新一期；当前 `weekly-2026-11-02`、7 篇、`schema_version: "1.1"`、`is_demo: false`。
- `data/papers/reports/YYYY-MM-DD.json`：历史快照；当前已确认 `2026-11-02.json`。
- `data/papers/schema-v1.1.json`：JSON Schema（draft 2020-12）。
- `data/papers/backups/2026-11-02-pre-v1.1.json`：升级前备份，仅为论文相关公开数据。

书目信息核实并不代表全文已读或科研结论已独立复现。具体依据参考论文对象内 `verification` 字段。发布日期归档及最新文件需分别回读确认；此公开 Feed 存在并不等于 DayBloom 网页已经接入。
